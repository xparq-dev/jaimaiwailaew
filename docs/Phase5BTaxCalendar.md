# Phase 5B — Tax Calendar

## เป้าหมาย

เผยแพร่หน้าปฏิทินกำหนดยื่นแบบภาษีเงินได้บุคคลธรรมดาแบบอ่านอย่างเดียว เพื่อให้ผู้ใช้
เตรียมข้อมูลได้ทันเวลา โดยไม่เปลี่ยนการคำนวณภาษี ไม่ยื่นแบบแทนผู้ใช้ และไม่ส่งข้อมูล
Workspace หรือข้อมูลการเงินออกจากอุปกรณ์

## ขอบเขต

- หน้า `/tax-calendar` แสดงเฉพาะกำหนดที่ตรวจสอบแล้วจากกรมสรรพากร
- แสดงแบบภาษี ปีภาษี ช่องทางยื่น และวันครบกำหนดอย่างชัดเจน
- ทุกกำหนดมีลิงก์ไปยังแหล่งอ้างอิงของกรมสรรพากรในแท็บใหม่
- หน้ากฎภาษีมีทางเข้าปฏิทินกำหนดยื่น
- เนื้อหาเป็น static local content ไม่มี API, Cloud Sync, notification, calendar sync
  หรือการประมวลผลข้อมูลผู้ใช้

## Guardrails

- วันครบกำหนดเป็นข้อมูลอ้างอิง ไม่ใช่คำแนะนำภาษีเฉพาะบุคคลหรือการยืนยันสิทธิ
- ก่อนยื่นจริง ผู้ใช้ต้องตรวจสอบประกาศล่าสุดจากกรมสรรพากรอีกครั้ง
- การเปลี่ยนหรือเพิ่มกำหนดต้องตรวจแหล่งทางการ บันทึกวันที่ตรวจสอบ และเพิ่ม test
  ที่ยืนยันวันและลิงก์ต้นทาง
- ห้ามใส่ Workspace ID, user ID, entry ID, rule-set ID หรือยอดคำนวณภาษีในหน้าปฏิทิน
- คง local-first, opt-in Cloud Sync และ fail-closed ของ Tax Rule Engine เดิม

## Acceptance criteria

- [x] แสดงกำหนด ภ.ง.ด.94 ปีภาษี 2569 สำหรับยื่นผ่านอินเทอร์เน็ต
- [x] แสดงกำหนด ภ.ง.ด.90/91 ปีภาษี 2568 สำหรับกระดาษและ e-Filing
- [x] ลิงก์แหล่งอ้างอิงเป็น `rd.go.th` และเปิดอย่างปลอดภัยในแท็บใหม่
- [x] ไม่มีการคำนวณภาษี การแจ้งเตือน การยื่นแบบ หรือ network call ใหม่
- [x] รองรับหน้าจอแคบโดยไม่เกิด horizontal overflow
